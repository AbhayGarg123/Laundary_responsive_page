# 🧺 Laundry Web App - Responsive Hero Section & Navbar

Yeh ek responsive front-end landing page project hai jo Laundry Web App ke **Navbar** aur **Hero Section** ko display karta hai. Is project mein CSS Flexbox aur Media Queries ka use karke Desktop, Tablet, aur Mobile screens ke liye responsive layout banaya gaya hai.

---

## 🚀 Features

* **Responsive Navbar:**
  * Desktop par full navigation links (`Home`, `Services`, `About Us`, `Contact Us`) aur `Username` button show hota hai.
  * Tablet screen par text sizes aur padding adjust hoti hain.
  * Mobile screen par navigation links hide ho jaate hain aur sirf **Logo** aur **Username** dikhta hai.
* **Responsive Hero Section:**
  * Desktop & Tablet screen par side-by-side (row) layout.
  * Mobile screen par `flex-direction: column` ke saath vertical layout.
  * Font sizes aur image scaling screen size ke according smoothly handle ki gayi hain.
* **Modern Flexbox Layout:** Non-standard display properties ki jagah Clean Flexbox CSS ka use kiya gaya hai.

---

## 🛠️ Technologies Used

* **HTML5:** Page structure aur semantic markup ke liye.
* **CSS3:** Custom styles, Flexbox layout, aur Responsive Design (Media Queries) ke liye.

---

## 📱 Responsive Breakpoints

| Device Category | Screen Width | Key Layout Changes |
| :--- | :--- | :--- |
| **Desktop** | > 900px | Full Navbar with links, side-by-side Hero layout |
| **Tablet** | 601px - 900px | Smaller font sizes, reduced image scaling |
| **Mobile** | <= 600px | Links hidden, vertical column layout (`flex-direction: column`) |
